PDF EXAMPLE CASES - run from this exercise directory:
  python3 ft_stream_management.py foo
Do not create foo; it is the missing-file example.
For the failed-save example:
  chmod 000 denied_fragment.txt
  python3 ft_stream_management.py ancient_fragment.txt
At the prompt, type: denied_fragment.txt
Expect [STDERR] Error opening file ... Permission denied, then Data not saved.
After the test:
  chmod 600 denied_fragment.txt
This uses a local denied file in place of the PDF's /etc/passwd destination.
Restore readability before adding fixtures to Git. Git does not preserve
these read/write permission bits; set chmod 000 locally for each test.
